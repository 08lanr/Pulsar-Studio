# Handoff · 2026-09-15 · please test the producer workflow

Ruobin asks: walk the producer workflow as someone with no knowledge of the
product and flag anything confusing. No spend is involved in demo mode.

## Start the app (demo mode, no database)

```
cd Pulsar-Studio
npm install
$env:DATA_SOURCE = "fixture"     # PowerShell; bash: export DATA_SOURCE=fixture
npm run dev
```

Open http://localhost:3200/login. ffmpeg must be installed for clips to
cut (`winget install Gyan.FFmpeg` on Windows, `brew install ffmpeg` on a
Mac, then open a fresh terminal). Without it, every clip row says so.

Demo data now persists per machine under `.uploads/fixture-state.json`,
so what you create survives restarts and the Reset demo button (Reset only
rebuilds the seeded demo studio, Xinghai Pictures).

## The two companies

- **Xinghai Pictures** — the seeded demo studio (fourteen titles, four
  rounds, demo results). Always rebuilt from the seed.
- **Idiots in Cars** — the company Ruobin tested with, shipped with the
  repository as a starter: one title, the first five minutes of an "Idiots
  in Cars" YouTube compilation (the XQC clip) split into five ~60 s
  episodes, no subtitles (`docs/demo/idiots-in-cars/ep1..5.mp4`, 720p).
  On your first start the engine cuts its clips in the background (a
  minute or two with ffmpeg); after that the company is yours — whatever
  you do with it is saved on your machine.

  The workflow to test, signed in as Idiots in Cars:

  1. "Episodes & subtitles": watch the "Ad clips" block under each episode
     fill in; preview a clip at phone size.
  2. "Ad campaigns" → new campaign → Generate ads → write the ad text on a
     card (it is the line TikTok shows above the video; nothing is drawn on
     the picture) → choose ads within the budget slots → Approve ads →
     Approve budget → Launch (the demo launches into a fake TikTok).
  3. Also try the cold path once: as Pulsar staff add a company, sign in as
     it from the login card, upload any short video, and see the same thing
     happen from zero.

## What to judge

- Is it obvious what a clip is, what "ad text" is, and where the text ends
  up? (It is the line TikTok shows above the video; it is never drawn onto
  the picture.)
- Do the budget slots make sense? ($50 per ad; Choose greys out when full.)
- Does anything say something the system does not actually do?
- Anything you had to guess at, note it in `docs/reviews/` or tell Ruobin.
