# Native Chinese pass on the producer portal (2026-09-08)

The producer portal's Chinese was a faithful translation of the English; the founders wanted it to read as if a Chinese product team had written it. DeepSeek (`deepseek-chat`, DeepSeek V3.2) did the rewrite and the wording analysis; a human review settled every change. This file is the summary. The full record is [zh-native-2026-09-08-report.md](zh-native-2026-09-08-report.md) (DeepSeek's analysis per batch, every accepted rewrite with its reason, every rejection) and the canonical term list is [zh-native-2026-09-08-glossary.json](zh-native-2026-09-08-glossary.json).

## Scope and register

- 1,508 keys: everything referenced from `app/(producer)`, `components/producer`, the shared components and `lib/`. Staff chrome (285 admin-only keys) and 558 unreferenced keys were not touched.
- Register chosen for this pass: 简体, neutral 你 (not 您), lighter than a formal B2B tone, the voice of a domestic SaaS console (巨量引擎 / 抖音精选联盟 backstage). Buttons are verb–object phrases, headers and labels are noun phrases without a full stop, hints are short full sentences; half-width spaces between CJK and Latin or digits; full-width punctuation inside Chinese.
- The product's meaning rules were locked, not just suggested: 收入/观众 always carry TikTok, 花费/点击率/结果 always carry 广告, 美国 stays wherever the English says US, the four evidence labels stay four distinguishable words, demo/simulated notes are never softened, and "not a success probability" style caveats stay.

## What DeepSeek found wrong with the current Chinese

From its overall critique and the 63 per-batch analyses:

1. **Translation-shaped sentences.** 打开其下一步操作, 没有什么在等你, 首份报告尚未到达, 有播放的进入, 为上一步的比例, 资金流入 — understandable, but no Chinese product writes them that way.
2. **One concept, several words.** 作品 / 剧集 / 项目 / 条目 for a title; 单集 / 集 / 分集 for an episode; 审核 / 审批 / 批准 for approval; 映射 / 关联 for the listing link; 观测 / 实测 and 估计 / 估算 for evidence; 剧本 for both a script and an episode.
3. **Bare metrics.** 收入, 观众, 花费, 点击率 appearing without their TikTok / 广告 qualifier, which the product's own rules forbid.
4. **Wrong form for the control.** Comparative or verb phrases on static labels (更清晰, 增加幽默), 打开 on buttons where a Chinese console says 查看, "一键" prefixes, and sentence-final full stops on short hints.
5. **Register drift.** 您 in some strings and 你 in others; "请" padding on instructions.

## What was accepted (353 strings)

- 作品 → 剧集 for a title and 分集 for an episode, everywhere in producer copy and in the metric registry (`lib/research/registry.ts`, `lib/research/source-copy.ts`).
- Evidence labels 实测 / 推断 / 估算 / 合作方上报; data states 可用 / 积累历史中 / 需要接入 / 人工导入 / 不可用 / 过期 / 失败.
- 花费 → 广告花费 in every ad context; 3 秒留存 → 开场留存; 版权窗口 → 授权窗口; 映射 → 关联; 人群 → 同期群 for cohorts; 观看用户 → TikTok 观众.
- Buttons: 打开 → 查看, 一键生成 → 生成, 创建新修订稿 → 新建修订稿; 第 {n}/{total} 步 → 第 {n} 步，共 {total} 步.
- Navigation and section names: 浏览作品 → 浏览上架剧集, 可探索的故事方向 → 选题参考, 结果说明了什么 → 结果解读, 保存后做什么 → 后续步骤.
- Sentence-level rewrites that removed translation-ese without changing meaning (see the report).

## What was refused (21 rewrites) and why

- Meaning changes: n/a → 暂无 (n/a and unavailable are distinct states), 下载英文剧本 → 下载英文分集 (it is the script), 占展示 {pct} → {pct} 的展示, 英文为空 → 英文行为空 (reads as 行为), 上一采集日 → 昨日 (collections can skip days), 酒店行政区 → 行政间.
- Product distinctions blurred: 平台条目关联 → 平台链接 (a listing link is not a URL), 广告活动信息 → 活动信息.
- Inconsistent with DeepSeek's own choices elsewhere: 入组 vs 同期群, 批准角色 vs 审批角色 (the role is 审批角色; the action is 批准), IAP vs 内购.
- The eight rewrite-direction tags (更直接, 更情感化, …) keep their comparative: they describe the direction of a rewrite, not a static quality.
- Four admin keys that were in the scan only because shared code references them.

Beyond DeepSeek's proposals, 15 strings it had marked "already fine" still said 作品 or 您 and were rewritten by hand so that neither word remains in producer copy.

## How to rerun

```bash
npx tsx scripts/zh-native/collect.ts      # scope → tmp/zh-native/keys.json
npx tsx scripts/zh-native/run.ts glossary # one DeepSeek call → glossary.json
npx tsx scripts/zh-native/run.ts translate # batches → tmp/zh-native/out/*.json (resumable)
npx tsx scripts/zh-native/apply.ts --write # checks + review.json → locales/_keys, then merge-locales
```

`DEEPSEEK_API_KEY` comes from `.env.local`. The run is developer tooling: it never touches `studio.jobs`, and nothing in the app calls DeepSeek unless `LLM_PROVIDER=deepseek`.
